## Install it as an app

**iPhone / iPad** — open the Arcade in Safari, tap **Share**, then **Add to Home Screen**.

**Android** — open it in Chrome, tap the **⋮** menu, then **Install app**.

**Mac / Windows** — in Chrome or Edge, click the **install icon** in the address bar.
